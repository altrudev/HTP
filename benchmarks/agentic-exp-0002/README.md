# Agentic EXP-0002 fixture

Small settings-persistence fixture for controlled coding-agent experiments.

Public API:

- `DurableStore`
- `SessionSnapshot`
- `SettingsService#get(key)`
- `SettingsService#set(key, value)`
- `SettingsService#shutdown()`

Run visible tests with:

```bash
npm test
```

This branch is disposable benchmark material and must not be merged into HTP `main`.
