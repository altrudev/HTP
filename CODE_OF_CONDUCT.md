# Code of Conduct

HTP is a technical open-source project. Participation should help produce a safer, clearer and more interoperable Human ↔ AI protocol.

## Expected behavior

Participants should:

- discuss ideas, evidence and implementation details rather than attack people;
- be specific when identifying a defect or disagreement;
- disclose relevant conflicts of interest when they materially affect a proposal;
- avoid harassment, threats, discriminatory abuse or deliberate intimidation;
- respect privacy and do not post private conversation data, credentials, signing keys or exploit material unnecessarily;
- follow the security-reporting process for undisclosed vulnerabilities;
- distinguish facts, measurements, assumptions and opinions in technical discussions.

Strong technical disagreement is welcome. Personal abuse is not.

## Unacceptable behavior

Examples include:

- harassment or discriminatory language directed at participants;
- publishing private personal information without permission;
- deliberate disruption of project discussions or review processes;
- knowingly submitting malicious code, fabricated test results or misleading provenance;
- using project communication channels to distribute undisclosed exploit instructions against HTP users or implementations.

## Enforcement

Project maintainers may edit, hide, lock or remove abusive or unsafe content and may restrict participation when necessary to protect contributors or project security.

Moderation decisions should be based on behavior in project spaces, not disagreement with a maintainer's technical position.

## Security exception

Good-faith security research is encouraged. Security findings that could enable exploitation should be reported through the process in [SECURITY.md](SECURITY.md) rather than treated as ordinary public discussion.
